# 鱈魚大叔消消樂 🐟

以我們的吉祥物「鱈魚大叔」和夥伴們為主角、玩法類似 Candy Crush 的可愛三消遊戲。
單一 HTML 檔案，不需要安裝任何東西，電腦和手機都能玩。

**線上玩：** https://viola2photo.github.io/cod-uncle-match/

## 怎麼玩

1. 在**關卡地圖**點選關卡，看完目標後按「開始」。
2. 滑動（或依序點選）兩個相鄰的角色交換位置，三個以上同樣的排成一線就會消除。
3. 在步數用完前完成**關卡目標**就過關，依分數拿 1～3 顆星，並解鎖下一關。

### 關卡目標

| 目標 | 說明 |
| --- | --- |
| 🎯 分數 | 拿到指定分數 |
| 收集角色 | 消除指定角色達到數量 |
| 冰塊 / 美乃滋 / 調味料 | 清掉棋盤上全部的該種障礙物 |

### 特殊方塊

| 組合 | 效果 |
| --- | --- |
| 連成 4 個 | 條紋方塊（清掉一整排或一整列） |
| 排成 L / T 形 | 發光方塊（清掉周圍 3×3） |
| 連成 5 個 | **彩虹鱈魚大叔**！和任何方塊交換，同一種全部消光；兩個大叔交換＝全場清空 |

### 棋盤形狀

每一關的棋盤形狀都不一樣（菱形、愛心、十字、沙漏、左右兩半……）。
沒有格子的地方，方塊往下掉時會直接穿過去。

### 障礙物

| 障礙物 | 層數 | 怎麼清掉 |
| --- | --- | --- |
| 冰塊 | 1～3 | 在**旁邊消除**或被特殊方塊打到，敲一下裂一層；冰塊固定不動，方塊從它後面穿過 |
| 美乃滋網 | 1～2 | 在它**上面消除**（或被特殊方塊打到）就變薄一層 |
| 調味料（辣椒粉 → 胡椒粒） | 1～2 | 角色被黏住**不能移動也不會掉落**；把它**湊進一排**消除一次就清掉一層 |

### 小魚生命

- 最多 5 隻小魚，**沒過關**或**玩到一半離開**會失去 1 隻。
- 每 20 分鐘游回 1 隻；小魚游光就要等。
- 進度（星星、小魚）存在瀏覽器裡，換手機或清除瀏覽資料會重來。

### 演出

- 左側面板的鱈魚大叔：平常正面，驚訝時轉側面，難過時側身低頭（遊戲裡不使用背面）。
- 主廚大叔的四種表情：換錯位置會**生氣**、4 連鎖以上**大笑**、過關**開心跳起來**、失敗**大哭**。
- 3 連鎖時糖霜米花跳出來歡呼。
- 鱈魚大叔的側面用在「彩虹鱈魚大叔」特殊方塊。

## 修改

都在 `index.html` 裡：

| 想改什麼 | 搜尋 |
| --- | --- |
| 角色名字、方塊圖片、盤子顏色 | `const TILES` |
| 關卡（步數、目標、星星分數、冰塊位置） | `const LEVELS` |
| 小魚數量、回復時間 | `MAX_LIVES`、`REGEN_MS` |

圖片都在 `assets/` 資料夾（已去背的 WebP），用同樣檔名覆蓋就能換圖。
小魚生命圖示目前是程式畫的暫代圖（`id="fish"`），正式素材到了再替換。

### 關卡格式

```js
{ moves: 24, stars: [2000, 3500, 5000], goals: [{ type: 'ice' }, { type: 'mayo' }], layout: [
  'xx....xx',
  'x.mm11.x',
  ...        // 一共 8 行，每行 8 個字
] }
```

| 字 | 意思 |
| --- | --- |
| `.` | 一般格子 |
| `x` | 沒有格子（用來做棋盤形狀） |
| `1` `2` `3` | 冰塊，數字是要敲幾下 |
| `m` `M` | 美乃滋 1 層 / 2 層 |
| `s` `S` | 調味料 1 層（胡椒粒）/ 2 層（辣椒粉） |

目標 `goals` 可以放好幾個：`score`（分數，要加 `n`）、`collect`（收集角色，要加 `tile` 和 `n`）、`ice`、`mayo`、`season`。
