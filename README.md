# 鱈魚大叔消消樂 🐟

以我們的吉祥物「鱈魚大叔」為主角的可愛風三消（消消樂）遊戲。
單一 HTML 檔案，不需要安裝任何東西，電腦和手機都能玩。

## 怎麼玩

- 直接用瀏覽器打開 `index.html` 即可。
- 滑動（或依序點選）兩個相鄰的海洋朋友交換位置，三個以上同樣的排成一線就會消除。
- 在步數用完之前達到目標分數就過關，剩下的步數會換成獎勵分數與星星。

| 組合 | 效果 |
| --- | --- |
| 連成 4 個 | 直線清除方塊（清掉一整排或一整列） |
| 排成 L / T 形 | 範圍炸彈（清掉周圍 3×3） |
| 連成 5 個 | **鱈魚大叔**！和任何方塊交換，同色全部消光；兩個大叔交換＝全場清空 |

## 角色

| 角色 | 在遊戲裡的位置 |
| --- | --- |
| **鱈魚大叔**（主角） | 左側面板的吉祥物：平常是正面，驚訝時轉成側面，難過時會轉身背對你；連成 5 個會變成大叔方塊 |
| **蝦餅小子** | 連成 4 個產生的直線清除方塊上會有他 |
| **小角角** | L / T 形產生的範圍炸彈上會有他 |
| **糖霜米花** | 連鎖 3 次以上時跳出來歡呼 |

消除用的六種海洋朋友：粉紅小章魚、黃色海星、藍色泡泡、橘色扇貝、綠色河豚、紫色愛心。

## 更換角色圖片或名字

- 圖片都在 `assets/` 資料夾（已去背的 WebP），用同樣檔名覆蓋就能換圖。
- 角色名字在 `index.html` 裡搜尋 `const CAST`，改 `name` 即可。

## 發布到網路上（GitHub Pages）

到倉庫的 **Settings → Pages**，Source 選擇要發布的分支，儲存後即可用
`https://<帳號>.github.io/<倉庫名稱>/` 分享給朋友玩。
