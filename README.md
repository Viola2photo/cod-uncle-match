# 鱈魚大叔消消樂 🐟

以我們的吉祥物「鱈魚大叔」為主角的可愛風三消（消消樂）遊戲。
單一 HTML 檔案，不需要安裝任何東西，電腦和手機都能玩。

## 怎麼玩

- 直接用瀏覽器打開 `index.html` 即可。
- 滑動（或依序點選）兩個相鄰的海洋朋友交換位置，三個以上同樣的排成一線就會消除。
- 在步數用完之前達到目標分數就過關，剩下的步數會換成獎勵分數與星星。

| 組合 | 效果 |
| --- | --- |
| 連成 4 個 | 條紋方塊（清掉一整排或一整列） |
| 排成 L / T 形 | 發光方塊（清掉周圍 3×3） |
| 連成 5 個 | **彩虹鱈魚大叔**！和任何方塊交換，同一種全部消光；兩個大叔交換＝全場清空 |

## 角色

### 六種消除方塊（用吉祥物的三視圖）

| # | 方塊 | 盤子 |
| --- | --- | --- |
| 1 | 鱈魚大叔（正面） | 黃色圓形 |
| 2 | 蝦餅小子（正面） | 粉紅方形 |
| 3 | 小角角（正面） | 藍色六角形 |
| 4 | 糖霜米花（正面） | 紫色花形 |
| 5 | 小角角（背面） | 綠色菱形 |
| 6 | 蝦餅小子（背面） | 青色膠囊形 |

每種方塊底下的盤子顏色和形狀都不同，正面和背面也能一眼分辨。
鱈魚大叔的側面則保留給「彩虹鱈魚大叔」特殊方塊。

### 其他演出

- 左側面板的鱈魚大叔：平常是正面，驚訝時轉成側面，難過時轉身背對你。
- 連鎖 3 次以上，糖霜米花會跳出來歡呼。

## 更換角色圖片或名字

- 圖片都在 `assets/` 資料夾（已去背的 WebP），用同樣檔名覆蓋就能換圖；消除方塊用的是 `tile-*.webp`。
- 方塊的圖片、盤子顏色在 `index.html` 裡搜尋 `const TILES`。
- 角色名字在 `index.html` 裡搜尋 `const CAST`，改 `name` 即可。

## 發布到網路上（GitHub Pages）

到倉庫的 **Settings → Pages**，Source 選擇要發布的分支，儲存後即可用
`https://<帳號>.github.io/<倉庫名稱>/` 分享給朋友玩。
